# 🍏 FruiterMan Fit

**FruiterMan Fit** es una aplicación moderna de fitness diseñada para ayudar a los usuarios a registrar sus entrenamientos de forma sencilla y visual, utilizando las últimas tecnologías de Android.

## 🚀 Características actuales
- **Registro de Entrenamientos:** Pantalla interactiva para añadir ejercicios, series, repeticiones y peso.
- **Estadísticas Reales:** Dashboard que calcula racha (streak), nivel de usuario y calorías quemadas basándose en datos reales de la base de datos.
- **Librería de Ejercicios:** Explorador de ejercicios con filtros por grupos musculares.
- **Persistencia Local:** Uso de Room para guardar todo el progreso sin necesidad de conexión constante.
- **Inyección de Dependencias:** Implementación completa con Hilt.

## 🛠️ Stack Tecnológico
- **Lenguaje:** Kotlin 2.0 (con el nuevo compilador de Compose).
- **UI:** Jetpack Compose (Material 3).
- **Arquitectura:** MVVM (Model-View-ViewModel).
- **Base de Datos:** Room.
- **DI:** Hilt (Dagger Hilt).
- **Network:** Retrofit & OkHttp (en proceso).
- **Imágenes:** Coil (soporte para GIFs animado).
