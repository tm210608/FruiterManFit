---

Interview the user relentlessly about every aspect of the current plan or design until we reach a shared understanding. Walk down each branch of the design tree, resolving dependencies between decisions one-by-one.

**Rules:**
- Ask one question at a time and wait for the answer before proceeding.
- For each question, provide a recommended answer based on the codebase and context.
- If a question can be answered by exploring the codebase, explore the codebase instead of asking.
- Keep drilling into each branch until all dependencies are resolved.
- Stop only when both you and the user agree the plan is fully understood and all gaps are closed.
